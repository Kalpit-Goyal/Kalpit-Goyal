### 💰 Financial Analyst Agent

> `Python` `LangGraph` `LangChain` `MCP` `RAG` `yfinance` `LLMs`

An **agentic financial analysis system** designed to combine LLM reasoning with real-time financial data and reusable tools.

* 🤖 Built an **agentic workflow** using LangGraph for structured financial analysis.
* 📊 Integrates financial market data through **tool-based workflows** rather than relying solely on LLM knowledge.
* 🔌 Uses **MCP** to separate financial tools from the core agent, making the system modular and reusable.
* 🧠 Combines **LLM reasoning, tool calling, and financial data retrieval** to answer analytical queries.
* 🏗️ Designed with a modular architecture so additional financial tools and data sources can be added independently.
* 🔍 Uses RAG/knowledge retrieval concepts where relevant to ground financial analysis.

### 🏥 MediScan AI — Multi-Disease Detection System

> `Python` `PyTorch` `FastAPI` `DenseNet-121` `EfficientNet-B3` `Grad-CAM`

A multi-modal medical imaging platform for detecting diseases across chest X-rays, retinal fundus images, brain MRI scans, and skin lesions.

* 🧬 Engineered **four independent deep learning models** for multi-modal medical image classification.
* 🧠 Used **DenseNet-121 and EfficientNet-B3** architectures.
* ⚡ Developed a **FastAPI inference service** with lazy model loading and image preprocessing.
* 🔬 Integrated **Grad-CAM explainability** for diagnostic heatmap visualizations.
* 📡 Returns structured JSON responses with predictions and confidence scores.

### ▶️ YouTube Video RAG Chatbot

> `Python` `ChromaDB` `FastAPI` `Google Gemini` `RAG`

A production-style RAG system that allows users to ask questions about long-form YouTube videos.

* 🎥 Extracts and processes **YouTube transcripts**.

* 🔎 Performs semantic retrieval before generating responses.
* 🧠 Uses **Google Gemini** with prompt engineering and conversation memory.
* 🏗️ Designed a modular ingestion and retrieval architecture with persistent vector storage.
