## 🚀 Featured Projects

### 🏥 MediScan AI — Multi-Disease Detection System
> `Python` `Flask` `ReactJS` `DenseNet-121` `EfficientNet-B3` `Grad-CAM`

A unified deep learning platform for detecting chest, skin, retinal, and brain diseases from medical imaging data (X-ray & MRI).
- 🔬 Hybrid **CNN-Transformer** architecture with **Grad-CAM** for explainable AI diagnostics
- 💻 Full-stack UI built with **Flask + ReactJS** — production-ready and live
- 🧬 Targets real-world clinical AI challenges with multi-modal disease detection

- 📈 **XGBoost** model trained on end-to-end feature-engineered data pipeline
- 💡 Tiered pricing strategy to balance lot occupancy and maximize space utilization
- 🏆 Capstone project — **Summer Analytics 2025, IIT Guwahati**
